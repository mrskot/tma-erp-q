# КОНСОЛИДИРОВАННЫЕ ПРАВИЛА ДЛЯ AI TMA-ERP-Q

## Общие правила разработки

### 1. Работа с данными
- Всегда используй реальные данные из базы данных вместо тестовых
- Используй правильные имена колонок из базы (batch_number вместо product_serial_number)
- Всегда проверяй структуру таблиц перед выполнением SQL операций
- Используй base64 для кодирования кириллицы в заголовках HTTP
- При создании заявок получай creator_telegram_id из req.user (middleware авторизации)

### 2. API разработка
- При создании API endpoints для пользователей используй фильтрацию по ролям
- Все endpoints должны быть идемпотентными, где это критично
- Реализуй пагинацию для всех list endpoints
- Добавляй валидацию входных данных
- Используй правильные HTTP статус коды
- Реализуй обработку ошибок с информативными сообщениями

### 3. Безопасность
- Всегда валидируй входные данные
- Используй prepared statements для SQL запросов
- Реализуй rate limiting для публичных endpoints
- Маскируй чувствительные данные в логах
- Используй HTTPS в production
- Реализуй CORS политики

2. Проверь UPDATES-PENDING.md

1. Обнови CHANGELOG-DETAILED.md
2. Обнови INDEX-CONTEXT.md
3. Перенеси выполненные задачи в архив
4. Подготовь план на следующую сессию
