# КОНТЕКСТ ПРОЕКТА TMA-ERP

## Общее описание
**TMA-ERP (TMA Enterprise Resource Planning)** - система управления предприятием с фокусом на управлении качеством продукции. Система предназначена для автоматизации процессов контроля качества, управления заявками на контроль и интеграции с внешними системами (Telegram, Bitrix24).

## Проблема/Возможность
### Проблема:
1. **Ручные процессы контроля качества** - бумажные заявки, ручной ввод данных
2. **Отсутствие мобильного доступа** - невозможность работы с системы вне офиса
3. **Разрозненные системы** - данные хранятся в разных местах (Excel, бумага, Bitrix24)
4. **Сложность отчетности** - ручное формирование отчетов по качеству

### Возможность:
1. **Цифровизация процессов** - автоматизация заявок на контроль качества
2. **Мобильный доступ через Telegram** - удобный интерфейс для мастеров и инспекторов
3. **Централизация данных** - единая система для всех данных по качеству
4. **Автоматическая отчетность** - генерация отчетов в реальном времени

## Целевая аудитория
### Основные пользователи:
1. **Мастера (Masters)** - создают заявки на контроль продукции
2. **Инспекторы ОТК (OTK Inspectors)** - проводят контроль, фиксируют результаты
3. **Администраторы (Admins)** - управляют системой, настраивают процессы
4. **Менеджеры (Managers)** - просматривают отчеты, анализируют качество

### Вторичные пользователи:
1. **Руководство предприятия** - мониторинг качества продукции
2. **Клиенты** - доступ к информации о качестве (опционально)

## Ключевые требования
### Функциональные требования:
1. **Управление пользователями** - роли, аутентификация, авторизация
2. **Управление партиями продукции (Lots)** - создание, отслеживание
3. **Каталог продуктов** - типы продуктов, чек-листы, время контроля
4. **Заявки на контроль (Applications)** - создание, статусы, история
5. **Фиксация расхождений (Discrepancies)** - документирование проблем
6. **Интеграция с Telegram** - мобильный интерфейс
7. **Синхронизация с Bitrix24** - обмен данными с CRM

### Нефункциональные требования:
1. **Производительность** - время отклика < 200 мс
2. **Доступность** - 99.5% uptime
3. **Безопасность** - аутентификация, авторизация по ролям
4. **Масштабируемость** - поддержка 100+ одновременных пользователей
