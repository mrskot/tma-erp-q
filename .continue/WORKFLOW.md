# WORKFLOW ОБНОВЛЕНИЯ ПРОМТОВ

## Роли:
- **Пользователь:** Определяет что нужно обновить
- **AI:** Вносит изменения, ведет логи, поддерживает структуру

## Процесс обновления:

### Между сессиями:
1. Пользователь работает над проектом
2. AI автоматически создает/обновляет UPDATES-PENDING.md на основе диалога
3. Пользователь может добавлять заметки в UPDATES-PENDING.md

### В начале сессии:
1. Пользователь: "Ознакомься с контекстом"
2. AI читает INDEX-CONTEXT.md
3. AI проверяет UPDATES-PENDING.md
4. AI готов к работе

### Во время сессии:
1. Пользователь описывает изменения
2. AI предлагает конкретные правки в файлы
3. Пользователь утверждает/корректирует
4. AI вносит изменения
5. AI обновляет CHANGELOG-DETAILED.md

### Команда "Внеси всё в промты":
1. AI: "Начинаю процесс обновления промтов"
2. AI показывает список изменений из UPDATES-PENDING.md
3. Пользователь утверждает/корректирует
4. AI последовательно обновляет все файлы
5. AI обновляет INDEX-CONTEXT.md (дату и изменения)
6. AI переносит обработанные обновления в архив
7. AI: "Обновление завершено"

## Правила для AI:
1. ✅ Всегда проверять INDEX-CONTEXT.md перед работой
2. ✅ Все изменения через утверждение пользователем
3. ✅ Вести детальный CHANGELOG-DETAILED.md
4. ✅ Сохранять обратную совместимость
5. ✅ Избегать дублирования информации
6. ✅ Обновлять статус в INDEX-CONTEXT.md
7. ✅ Архивировать выполненные обновления

## Формат UPDATES-PENDING.md:
```markdown
# ОБНОВЛЕНИЯ ДЛЯ ВНЕСЕНИЯ

## [Дата] - [Краткое описание]

### Изменения в документации:
- [ ] Файл: описание изменения
- [ ] Файл: описание изменения

### Новые файлы:
- [ ] Путь/файл.md: назначение

### Вопросы для обсуждения:
1. Вопрос 1
2. Вопрос 2

### Приоритет:
- Высокий/Средний/Низкий
```

## Формат CHANGELOG-DETAILED.md:
```markdown
# ДЕТАЛЬНАЯ ИСТОРИЯ ИЗМЕНЕНИЙ

## [Дата]
### Изменения:
- **Файл:** что изменено (кем)
- **Файл:** что изменено (кем)

### Причина изменений:
[Описание причины]

### Утверждено:
[Пользователь/дата]
```

## Начало работы:
1. AI создает базовую структуру
2. AI переносит контент из .continue OLD
3. AI наполняет основные файлы
4. Система готова к использованию
