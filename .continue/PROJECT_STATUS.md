## 🏗️ Архитектурные достижения (Январь-Февраль 2026)

### 1. Бэкенд (Node.js + Knex)
- **BaseModel Pattern**: Внедрен базовый класс для всех моделей.
    - Единый стандарт CRUD.
    - Безопасное создание записей (insert -> select) для совместимости SQLite/PostgreSQL.
    - Встроенная поддержка Soft Delete (`is_active`).
- **Слоистая архитектура**: Четкое разделение `Controller -> Service -> Model`.
- **Централизованная логика**: Режимы контроля (LITE/HARD) вынесены в `discrepancyService`.

### 2. Фронтенд (Vanilla JS SPA)
- **State Management**: Внедрено сохранение состояния фильтров в `store.js` ("Smart Filters").
- **API Wrapper**: Глобальный перехватчик запросов с индикацией загрузки (Loader).
- **Component Communication**: Улучшено взаимодействие модальных окон через систему колбэков (`onSave`).
- **Memory Leak Fix**: Механизм `cloneNode(false)` в `app.js` для предотвращения дублирования обработчиков событий ("Ghost Listeners").

## 🛠️ Реализованная бизнес-логика

### Жизненный цикл Несоответствий (Discrepancy Flow)
- **Создание**: Из заявки с автоподстановкой ответственного мастера.
- **Устранение (Мастер)**:
    - Кнопка "Устранено" (с обязательным фото в HARD режиме).
    - Кнопка "Оспорить" (выбор причины: "Другой ответственный" или "Требуется КР").
- **Закрытие (Инспектор)**:
    - Сценарии закрытия: `Fixed` (Исправлено), `Resolution Card` (КР), `Scrap` (Брак), `Political` (Политическое решение).
- **Автоматизация**: В режиме **LITE** (настраивается в Product) дефект закрывается автоматически при нажатии мастером "Устранено".
